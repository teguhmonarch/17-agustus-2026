🇮🇩 Customer Intelligence Platform — API

REST API over 14,999,896 customer records (PostgreSQL 14). All responses are JSON; all metrics are computed live. Base URL: http://168.144.244.142:3000. Interactive dashboard at /.

GET /api/health

Readiness + exact record count. Also at /health.

{ "status":"ready", "ok":true, "total_records":14999896, "database":"connected", "timestamp":"..." }

GET /api/search

ParamDescription
qquery string
typeemail · phone · user_id · name (fuzzy)
limit1–100 (default 10)
offsetpagination offset
GET /api/search?q=komang&type=name&limit=10&offset=0

{ "query":"komang","type":"name","limit":10,"offset":0,
  "results":[{ "user_id":1234567,"full_name":"Komang Pipit",
    "user_email":"...","msisdn":"0812****90","status":1,"created_at":"..." }],
  "total":42,"took_ms":78.4 }

Phone numbers are masked. Exact types <100ms, name <300ms (p50).

GET /api/quality   GET /api/metrics

Full data-quality report (email/phone/birth_date/hobbies/status metrics, duplicate + invalid detection, severity-tagged issues). /api/metrics returns a compact {duplicates, missing_fields, quality_score} summary.

GET /api/quality  → { "total_records":14999896, "quality_metrics":{...}, "data_issues":[...] }

GET /api/duplicates/:user_id

Possible duplicates for one user. Query: threshold (default 0.7), limit. Composite score = email·0.4 + phone·0.4 + name_similarity·0.2 (normalized Levenshtein).

GET /api/duplicates/53462510?threshold=0.5

{ "user_id":53462510,"full_name":"...","possible_duplicates":[
  { "user_id":69461426,"similarity_score":0.6,
    "match_reasons":["email_exact_match","name_similarity_1.00"],"confidence":"low" }],
  "total_possible_duplicates":1 }

POST /api/duplicates

Global duplicate pairs (bounded sample) + total count. Optional JSON body { "user_id": 123 } routes to the per-user detector.

POST /api/duplicates
{ "duplicates":[{"id1":53462510,"id2":69461426,"similarity":1}], "count":982381 }

GET /api/duplicates/find

Duplicate accounts detected by a shared IP address (same device/location). Joins ws_user_activity + ws_user. Params: method=ip_address, limit (default 50).

GET /api/duplicates/find?method=ip_address&limit=50

{ "method":"ip_address","count":50,"groups":[
  { "ip_address":"192.168.206.236","user_count":57,
    "users":[{ "user_id":311790,"full_name":"...","user_email":"..." }] }]}
